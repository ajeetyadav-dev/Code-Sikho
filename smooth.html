How It Works

Built for buttery motion

Spring Dynamics

Every movement uses real spring physics with configurable stiffness and damping. No linear interpolation, no robotic easing.

GPU Composited

Only transform and opacity are animated. Everything stays on the compositor thread, bypassing the main thread entirely.

Zero Jank Guarantee

A single rAF loop drives all animations. No layout thrashing, no forced reflows, no style recalculations mid-frame.
