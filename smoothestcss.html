GPU Compositing

Only animating transform and opacity ensures the browser stays on the GPU compositor thread, bypassing the main thread entirely.

📈

Custom Easing

Pre-built easing functions like "ease" feel mechanical. Custom cubic-bezier curves like (0.16, 1, 0.3, 1) create organic deceleration.

🧱

Layer Promotion

will-change and backface-visibility: hidden promote elements to their own compositor layers, eliminating paint bottlenecks.

🎯

Sub-pixel Precision

Using translate3d() instead of translate() forces sub-pixel rendering on the GPU, eliminating the jitter common with integer snapping.
