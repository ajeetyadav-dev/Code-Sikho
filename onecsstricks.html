The Source

12 Lines of CSS

That's all it takes. No libraries. No frameworks. No JavaScript.

style.css 
/* Register the custom property for animation */
@property --angle {
  syntax: "<angle>";
  initial-value: 0deg;
  inherits: false;
}

.card {
  position: relative;
  border-radius: 20px;
  overflow: hidden;
}

.card::before {
  content: '';
  position: absolute;
  inset: -2px;
  background: conic-gradient(from var(--angle), gold, transparent 40%, gold 50%, transparent 90%);
  animation: spin 4s linear infinite;
  z-index: -1;
}

@keyframes spin { to { --angle: 360deg; } }
