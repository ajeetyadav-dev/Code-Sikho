Core Features

Everything feels alive

Every surface responds to your presence. Light follows intent.

Cursor Spotlight
A radial gradient tracks your cursor position in real-time, creating an organic light source that breathes life into static elements.
Learn more
Border Illumination
The card border lights up nearest to your cursor using CSS mask compositing — no JavaScript rendering, pure GPU acceleration.
Learn more
Zero Performance Cost
No canvas, no requestAnimationFrame loops for the spotlight. Just CSS custom properties updated on mousemove — butter smooth at 120fps.
Learn more
Composable Layers
Stack multiple spotlight layers — inner glow, border glow, content reveal — each with independent radius, opacity, and blend mode.
Learn more
Graceful Fallback
On touch devices, the spotlight activates on the first touch position and remains static — no broken interactions, no jank.
Learn more
Theme Adaptable
Swap one color variable and the entire spotlight system adapts — gold, cyan, rose, green. Works on any background.
