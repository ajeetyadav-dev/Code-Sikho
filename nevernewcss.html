01 — @property

Animate the Unanimatable

CSS gradients normally snap between states — they can't be transitioned. But @property registers a custom property with a type, making it interpolatable. The difference is jaw-dropping.

Without @property — Snaps

Jarring color jumps. This is what we've lived with.

With @property — Silky Smooth

Buttery smooth interpolation. Same keyframes, totally different result.

/* Register the property with a type */ @property --c1 { syntax: '<color>'; initial-value: #ff6b35; inherits: false; } /* Now animate it — CSS knows it's a color */ @keyframes smooth-grad { 0%, 100% { --c1: #ff6b35; --c2: #00d4aa; } 50% { --c1: #00d4aa; --c2: #ff2d7b; } }

02 — :has()

The Parent Selector We Waited For

For 25 years, CSS could only look down the DOM. :has() finally lets you style a parent based on its children. Click the checkboxes below — the entire card transforms.

:has() + form validation styling

The border glows when focused, turns green when valid

/* Style the parent based on child state! */ .card:has(input:checked) { border-color: var(--accent); transform: translateY(-6px); box-shadow: 0 24px 64px -16px rgba(255,107,53,0.2); } /* React to form validation state */ .form:has(input:valid) { --status-color: green; } .form:has(input:invalid) { --status-color: red; }

03 — Scroll-Driven Animations

Animate on Scroll, Zero JavaScript

No IntersectionObserver. No scroll event listeners. No requestAnimationFrame. Just pure CSS linking animation progress to scroll position via animation-timeline: view().

Scroll progress tied to this element's visibility

Fade Up

Blurs in and rises as you scroll

Slide Left

Enters from the left side

Slide Right

Enters from the right side

.scroll-reveal { animation: scroll-in linear both; animation-timeline: view(); /* ← the magic line */ animation-range: entry 0% entry 100%; } @keyframes scroll-in { from { opacity: 0; transform: translateY(50px); filter: blur(6px); } to { opacity: 1; transform: translateY(0); filter: blur(0); } }

Note: Scroll-driven animations require Chrome 115+ or Edge 115+. Other browsers show static fallback.

04 — @starting-style

Animate display: none

You literally cannot transition from display: none — until now. @starting-style defines where the transition begins when an element first renders. Press the button and watch elements materialize from nothing.

Pure CSS animation

.item { opacity: 1; transform: translateY(0) scale(1); transition: 0.55s cubic-bezier(0.34, 1.56, 0.64, 1); @starting-style { /* ← where to come FROM */ opacity: 0; transform: translateY(30px) scale(0.85); } } .item[hidden] { display: none; } /* Remove [hidden] → animates FROM starting-style TO normal */

05 — color-mix()

Mix Colors in CSS

No preprocessor. No color math libraries. color-mix() blends two colors right in the browser. Drag the sliders to see it live.

Mix Percentage 50%

/* Mix 50% orange with 50% teal, in sRGB */ background: color-mix(in srgb, #ff6b35 50%, #00d4aa); /* Create hover variants without precomputing */ .btn:hover { background: color-mix(in srgb, var(--accent) 80%, white); }

07 — offset-path

Motion Paths Without JavaScript

Animate elements along any SVG path — curves, loops, zigzags — with a single CSS property. No requestAnimationFrame, no path math. Just offset-distance: 0% → 100%.

.dot { offset-path: path('M30,120 C120,20 ... 780,120'); offset-rotate: auto; animation: follow 5s ease-in-out infinite alternate; } @keyframes follow { from { offset-distance: 0%; } to { offset-distance: 100%; } }

08 — clip-path Morphing

Shape-Shifting with Pure CSS

Animate between any polygon shapes by interpolating clip-path: polygon() values — as long as both have the same number of points. Pentagon to square to circle to hexagon, all in one keyframe.

The Shapes It Cycles Through

Pentagon — polygon(50% 0%, 100% 38%, 82% 100%, ...)
Rounded Square — polygon(50% 0%, 93% 25%, ...)
Circle — circle(45% at 50% 50%)
Hexagon — polygon(50% 0%, 85% 15%, ...)
@keyframes morph { 0%, 100% { clip-path: polygon(50% 0%, 100% 38%, 82% 100%, 18% 100%, 0% 38%); } 25% { clip-path: polygon(50% 0%, 93% 25%, 93% 75%, 7% 75%, 7% 25%); } 50% { clip-path: circle(45% at 50% 50%); } 75% { clip-path: polygon(50% 0%, 85% 15%, 100% 50%, 85% 85%, 50% 100%, 15% 85%, 0% 50%, 15% 15%); } } /* Same number of vertices = smooth interpolation */
