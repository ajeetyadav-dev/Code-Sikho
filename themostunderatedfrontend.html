Under the Hood

The entire effect in CSS

No canvas. No WebGL. No build step. Just three things CSS couldn't do before @property: animate gradient positions, interpolate custom properties, and keep it all on the GPU.

/* Step 1: Register custom properties as animatable */ @property --bx1 { syntax: '<percentage>'; initial-value: 25%; inherits: false; } /* Step 2: Use in gradient positions */ .mesh { background: radial-gradient(circle at var(--bx1) var(--by1), #FF6B35 0%, transparent 45%), radial-gradient(circle at var(--bx2) var(--by2), #FBBF24 0%, transparent 45%), /* ... more layers */ ; filter: blur(70px); animation: drift1 14s ease-in-out infinite alternate; } /* Step 3: Animate — this was impossible before @property */ @keyframes drift1 { 0% { --bx1: 20%; --by1: 15%; } 50% { --bx1: 75%; --by1: 70%; } 100% { --bx1: 35%; --by1: 80%; } }
