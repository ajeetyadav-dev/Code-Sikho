Buttons With Cursor-Tracked Border Glow

Same trick, applied to buttons. A spinning conic gradient border that only appears near your cursor position. Each button can have different gradient colors.

conic-gradient + mask-composite: exclude
The Recipe

The Entire Trick in 6 Lines

This is all it takes. One pseudo-element, one mask with two layers, one compositing operation.

premium-ui.css 
/* The One Trick */
.element::before {
  background: conic-gradient(from 0deg, gold, rose, teal, gold);
  -webkit-mask:
    linear-gradient(#fff 0 0) content-box,
    radial-gradient(circle 150px at var(--mx) var(--my), #000);
  -webkit-mask-composite: xor;      /* THIS IS THE LINE */
  mask-composite: exclude;          /* Standard property   */
  padding: 1.5px;                    /* Border thickness    */
}

/* JavaScript — just set two variables */
el.addEventListener('mousemove', e => {
  const r = el.getBoundingClientRect();
  el.style.setProperty('--mx', (e.clientX - r.left) + 'px');
  el.style.setProperty('--my', (e.clientY - r.top) + 'px');
});
